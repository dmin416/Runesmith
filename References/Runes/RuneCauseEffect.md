# Rune Cause and Effect

> **Rewrite lock.** Sample → segments understood → immediate logical applications. Named catalog dates: `Runes.md`. Worldview: `Nature.md`. Stage jobs: `RuneSystem.md`. Craft look/feel: `RuneCraftScrapes.md`.

This file is the living map of **what Roland learns when** and **what he does with it**. Source pacing that makes him sit on parts for months without combining them is discarded. He is intuitive and causal: once Diagnosis shows a segment's job, he uses it.

## Core rule

1. A rune is a machine of **segments** (large stages with jobs). Same rules across samples (`Nature.md`).
2. **Technology + Diagnosis** fill knowledge gaps **on encounter**. He does not need a teacher to name a stage once he has seen it work.
3. Learning a segment unlocks every machine that needs that job, limited only by:
   - **Sample access** (must see a working pattern at least once)
   - **Craft skill** (Scribe for paper; Runecraft + Blacksmith for durable metal)
   - **Mana / setup cost** (pool and Mastery; empty-mana tension stays)
   - **Rank ceiling** (Lesser linear chain vs Common coupled stages)
4. He does **not** wait for plot permission. Light + target-sense/attach → targeting attack the same research session. Fire isolated from Fire Arrow → fireball, torch, kettle heat, forge assist, whatever the job is.
5. Failed grafts are **fault diagnosis** (red pathways), not "random swap for a week." He isolates, swaps one stage, reads the fault, fixes or abandons.

## Segment library (jobs)

Names below are design labels. Prose can stay plain ("the fire part," "the seeker," "the weight stage").

| Segment job | What it does | Typical first sample |
|---|---|---|
| **Intake** | Pulls mana from user / stone / ambient feed | Any schematic |
| **Feed / pathway spine** | Routes mana between stages | Any schematic |
| **Converter: Fire** | Mana → heat / flame | Fire Orb, Fire Arrow |
| **Converter: Force / Impact** | Mana → mass/weight surge or kinetic shove | Impact |
| **Converter: Blast** | Mana → sharp internal explosion | Detonation |
| **Converter: Frost** | Mana → cold | Frost Arrow / Frost Bolt |
| **Converter: Wind / Gale** | Mana → air push / speed | Gale Arrow |
| **Converter: Water** | Mana → water mass | Aqua Ball |
| **Converter: Light** | Mana → light | Orb of Light |
| **Converter: Pure mana** | Mana stays mana (bolt / blade / barrier body) | Mana Arrow spell form; Mana Slash later |
| **Shape: Orb** | Holds output as a ball | Fire Orb, Orb of Light, Aqua Ball |
| **Shape: Arrow / bolt** | Projects a thin fast packet | Fire / Frost / Gale Arrow |
| **Shape: Tip / edge** | Concentrates on weapon tip or edge | Detonation tip; Sharpness; Scorch |
| **Constrain / contain** | Stops premature dump (orb does not explode on form) | Fire Orb |
| **Velocity / launch** | Gives heading and speed | Fire Orb; arrow family; Velocity |
| **Arrow body (shared)** | Common middle stages shared by elemental arrows | Fire + Frost + Gale Arrow comparison |
| **Attach / seek / sense target** | Locks effect onto a marked or sensed target | Shop seeker scrolls; life-detect / tracking samples when bought; later armor scan |
| **Trigger: contact** | Arms until tip inserts / hits | Detonation hold-lock |
| **Trigger: pressure / step** | Dormant until weight or open | Mine adapt from Detonation |
| **Trigger: user will** | Manual activate | Most gear runes |
| **Sustain / coat** | Thin mana layer that stays (hardening, resist) | Hardening; resistance suite |
| **Resist: Fire / Poison / Curse / …** | Sheds or blocks that harm type | Armor resistance samples (Fire Resist trial; full suite when he has them) |
| **Stat pad** | Temporary attribute bump (MP tax) | Fortitude |
| **Socket / Slot** | Seats a mana stone as battery / filter | Invented mid-Blacksmith |
| **Prime / hub** | Kill-switch or array core | Complex arrays (later) |

Add rows when a new sample teaches a new job. Do not invent jobs without a sample or a clear graft from known stages.

## Immediate application law

| If he has … | He can build … |
|---|---|
| Fire converter + Orb shape + constrain + velocity | Fire Orb (already); any orb-shaped fire tool |
| Fire converter alone (stripped from arrow/orb) | Torch, kettle heat, cook plate, forge assist, flame jet, fireball (new shape), Fire Arrow (if he has arrow body) |
| Light converter + Orb shape | Light Orb; camp light; signal flare; dazzle if overcharged |
| Light + attach/seek/sense | Homing light tag; targeting attack that rides the seeker onto a sensed mark |
| Fire + attach/seek | Homing firebolt / seeking Fire Arrow |
| Blast + contact trigger | Tip detonator (rapier form) |
| Blast + pressure trigger | Mines, door bombs, trip scrolls |
| Blast + Fire Orb | Grenade / firecracker scroll |
| Impact + arrow body + velocity | Heavy / weighted arrow (paper weak; metal or dense tip better) |
| Impact + weapon tip timing | Sahildr-style hammer/mace hit |
| Gale + Fire (partial) | Smoke / turbulence grafts (weak until pathways clean) |
| Frost + Orb or Arrow | Frost bolt, frost arrow, chill plate |
| Water + Orb | Aqua Ball; wash / douse tools |
| Pure mana + edge shape | Mana Slash / blade forms (when he has that sample) |
| Resist Fire on ladle/armor | Heat gear; kitchen and forge safety |
| Any converter + sustain coat | "Always on" tool versions (costlier) |

**Craft host still matters:** paper = disposable scroll / test. Metal = reusable tool/weapon (needs Blacksmith + Runecraft). He will still **design** the metal version on paper the day he understands the segments.

## Story conflict after early fluency

When segment logic is allowed, early tension is not "mystery of runes." It is:

- Mana and time to pour Highest boards and scrolls
- Mats cost (ink, skins, later metal)
- Who notices a kid with too many functional SKUs
- Contracts, identity hide, dwarven / guild interest
- Rank walls (some couples need Common+ resonance)
- Helci / party: he can keep them safer; stakes move to politics and bigger monsters
