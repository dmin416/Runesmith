## 3. Material Palette

### Steels

| Grade | Type | Uses | Typical treatment |
|---|---|---|---|
| 1018 / 1020 | Low carbon | Brackets, sheet parts, frames, body structure | As rolled, normalized, or carburized |
| 1045 | Medium carbon | Shafts, axles, sprockets, sway bars | Induction hardened or quench and tempered |
| 1541 | Medium carbon manganese | Axle shafts | Induction hardened |
| 4130 (chromoly) | Low alloy | Motorcycle and race car frames, roll cages, thin wall tube | TIG welded, normalize optional for thin wall |
| 4140 | Medium carbon chromoly | Crankshafts (moderate output), connecting rods, axles, studs, gears | Oil quench, temper to 28-36 HRC; can be nitrided |
| 4340 | Nickel chromoly | High-performance crankshafts, rods, axles, landing gear class parts | Oil quench, temper to 30-44 HRC |
| 8620 | Carburizing | Transmission gears, ring and pinion, U-joint crosses, wrist pins, camshafts | Carburize, oil quench, temper 150-180°C |
| 9310 | High-nickel carburizing | Highest load gears, racing transmissions | Carburize, quench, temper |
| 52100 | High carbon chromium | Bearing races, balls and rollers | Oil quench from about 840°C, temper about 160°C to 60-64 HRC |
| 5160 | Spring steel | Leaf springs, coil springs, sway bars, clutch diaphragm springs | Oil quench, temper to about 44-50 HRC |
| 9254 / chrome silicon | Spring steel | Valve springs, high-stress coil springs | Oil temper, stress relieve, shot peen |
| 1095 | High carbon | Knives, cutting tools, clock springs | Water or fast oil quench, temper |
| 410 / 420 | Martensitic stainless | Brake rotors on motorcycles, blender blades, knives | Harden and temper |
| 430 | Ferritic stainless | Appliance panels, induction-compatible cookware, exhaust trim | Annealed |
| 304 | Austenitic stainless | Kettles, sinks, pots, dishwasher tubs, exhaust systems, spokes | Annealed; work hardens heavily during forming |
| 316 | Austenitic stainless with molybdenum | Marine and chemical exposure | Annealed |
| 21-4N | Austenitic valve steel | Exhaust valves | Solution treated and aged |
| A2 / D2 / H13 | Tool steels | Dies, molds, punches, forging dies | Vacuum hardened, multiple tempers |

### Irons

| Type | Uses | Notes |
|---|---|---|
| Gray iron (class 30-40) | Engine blocks, heads, brake rotors and drums, flywheels, cylinder liners, lathe beds, skillets | Graphite flakes damp vibration and conduct heat; brittle in tension; machines beautifully |
| Ductile (nodular) iron | Cast crankshafts, differential carriers, steering knuckles, calipers, exhaust manifolds (high silicon moly grade) | Magnesium treatment makes graphite form spheres; far tougher than gray iron |
| Compacted graphite iron | Diesel blocks and heads | Between gray and ductile |
| White / chilled iron | Cam lobes, wear surfaces | Very hard, very brittle, formed by fast cooling |
| Austempered ductile iron (ADI) | Gears, suspension parts | Ductile iron austempered for strength close to forged steel |

### Aluminum

| Alloy | Form | Uses |
|---|---|---|
| A356 / A357 | Cast, T6 | Cylinder heads, wheels, crankcases, fork lowers, calipers |
| 319 | Cast | Engine blocks and heads |
| A380 | Die cast | Transmission cases, appliance housings (not heat treatable due to porosity) |
| A390 | Cast hypereutectic | Pistons, linerless blocks |
| 4032 | Forged | Pistons (low thermal expansion) |
| 2618 | Forged | High-performance pistons (tougher, expands more) |
| 6061 | Wrought, T6 | Machined brackets, triple clamps, swingarms, rims |
| 7075 | Wrought, T6 | High strength clamps, sprockets, levers (not weldable for structure) |
| 1100 / 3003 / 5052 | Sheet | Body panels, tanks, fenders, appliance parts, cookware |

### Copper and copper alloys

| Alloy | Uses |
|---|---|
| C110 ETP copper / C101 oxygen-free | Motor windings, wiring, magnetron anodes, radiator fins, head gaskets |
| C360 free-machining brass | Carburetor jets, fittings, gas valves, orifices |
| Cartridge / yellow brass | Radiator tubes and tanks |
| Phosphor bronze | Bushings, valve guides, springs, electrical contacts |
| Manganese bronze | Synchronizer rings, worm wheels |
| Aluminum bronze | Valve guides, heavy-duty bushings, worm wheels |
| Beryllium copper | Valve seats in racing heads, springs (beryllium dust is a serious inhalation hazard during machining) |

### Other metals

| Material | Uses |
|---|---|
| Ti-6Al-4V | Performance connecting rods, valves, fasteners, springs |
| Inconel 718 / 625 | Turbocharger parts, exhaust valves in extreme engines |
| Nichrome 80/20 | Heating elements (toasters, hair dryers) |
| Kanthal (FeCrAl) | High-temperature heating elements |
| Tungsten | Light bulb filaments, ignition point contacts |
| Babbitt (tin or lead base) | Poured plain bearings on vintage engines |
| Silicon electrical steel (M19 etc.) | Motor, alternator and transformer laminations |
| Lead / lead-calcium | Battery grids |
| Zamak 3 (zinc) | Carburetor bodies, door handles, appliance parts |

### Non-metals

| Material | Uses |
|---|---|
| Natural rubber | Tire carcass and tread blends, engine mounts |
| SBR | Tire tread |
| Butyl | Inner tubes, tire inner liners |
| EPDM | Coolant hoses, door and window seals |
| Nitrile (NBR) | Oil and fuel seals, O-rings |
| Viton (FKM) | Fuel system seals, high temperature |
| Silicone | Kitchen gaskets, high temperature hoses |
| PTFE | Brake hose liners, nonstick coatings, bushings |
| Alumina ceramic | Spark plug insulators, heating element supports |
| Mica | Toaster element cards, commutator insulation |
| Magnesium oxide powder | Insulation inside sheathed heating elements |
| Soda-lime glass | Windows, bulbs |
| Borosilicate glass | Oven doors, kettles, blender jars, measuring cups |
| PVB | Windshield interlayer |
