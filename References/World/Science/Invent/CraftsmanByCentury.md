# Craftsman By Century

What a modern-knowledge craftsman can push into Caldris one or two centuries early. Era ceiling: `../../Tech/Technology.md`. Forge→lathe: later MedievalIndustrialization. Metallurgy: `../Metallurgy/CraftMetal.md`. Batteries: `../Energy/Batteries.md`.

## Narrative

Materials and machining precision set the limit. Knowledge skips calendar years. It does not skip tight metal tolerances before the tools exist.

## Detail

| Era | Invent / improve band |
|---|---|
| 500s–900s | Lye soap; sand-charcoal filters; proper Q+T knives/axes; horse collar; moldboard plow; rocket stove / chimney |
| 1000s | Spinning wheel; treadle loom; Cu/brass still (antiseptic spirit); raised wool mattress; lime plaster |
| 1100s | Convex reading lenses; magnetic compass; wheelbarrow; glazed cookware |
| 1200s | Concave spectacles; rag paper + woodblock; lice combs; sealed grain bins; masonry stoves |
| 1300s | Plague linens / boiled bedding; spring steel (locks, tools, suspension); fitted plate; verge clock |
| 1400s | Movable type (**invent-only**; mass printing not baseline, `../../Tech/Technology.md`); bead microscope; wheel lathe; framed glass panes |
| 1500s | Pendulum clock; liquid thermometer / barometer; cistern flush toilet; paired-lens telescope |
| 1600s | Cowpox kit; atmospheric steam pump; lightning rod; Leyden jar / electrostatic |
| 1700s | Voltaic pile; electromagnet / telegraph; canned food; sewing machine; kick bicycle; Portland cement |

### Core bottleneck

Before ~**1750**, tight metal tolerances are the hard gate. Steam, firearms and precision machines need lathes, screw-cutting and flat references first. Build the toolmaking stack before the gadget.

### Caldris filter

Mass printing stays missing (`Technology.md`). Movable type / press products in this table and in `MedievalIndustrialization.md` are **invent-only**, not Caldris baseline. Common pencils / civilian lamps are invent gaps. Chemical cells are a side path next to stones (`../Energy/Batteries.md`). Do not invent D's personal product line here.
