# Roland Status (Source Scan)

Source scanned: `../Source/*.md` (primary on-disk Source dump).

Name on status: **Roland Arden**. Public alias: **Wayland**. No separate "D" status name found in Source dumps.

Highest character level seen on a Roland status dump: **L252** (`681-690`).

Highest primary class level seen in Source: **T3 Runesmith Overlord L77** (`681-690`). Rewrite T3 hard-cap is **L75** (`../Progression/Progression.md`); do not re-import L77 as live.

Notes:

- Levels below are the **highest level explicitly shown** for that skill in Source. Many late skills stay at L1 in text even if used later.
- Skill upgrades keep both forms listed when Source shows the rename (example: Identify -> Analyze -> High Analyze).
- **Diagnosis** and **Technology** do not appear as named skills. Earth-carry skills are Debugger, Circuitry and Tinkerer.
- Excluded other characters' gains (Agni, Bernir Soulsmith, Millie Arcane Calligrapher, Lucille Rune Transmuter, Robert Arch-Knight / Rune Vassal and similar).
