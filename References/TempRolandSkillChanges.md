# Temp: Roland Skill Changes

Temporary pass. Apply world laws from `Ideas.md`: skills **L1–L9 then evolve**, effects must be felt, ranged focus, no Source padding. Merge into `Skills.md` / chapter screens when locked; delete or archive this file after.

**Global rules for every skill below**

- Cap at L9. No L10 on the same name. Evolution starts the next form at L1 (unless noted as higher-order or tier-gated).
- For **build skills** (combat, runes, perception, core craft): numbers big enough that L1 matters and L9 changes plans. Soft “slightly faster / small bonus” text is banned.
- **Flavor / behind-the-scenes skills** (Sleep Resistance, Cooking, Technology, Acting, Basic Mathematics, Map Reading, and similar): keep light. They help in the background and justify scenes; do not redesign into combat math or heavy % tables.
- Stat bonuses tied to level stay fine.
- Class-gated skills stay gated. Timing can still move earlier when Early Logical Skills says so.

## Childhood combat basics (~Ch 4–7)

World law: **Basic X** maxes at L9 → evolves to non-Basic form. Chapter 7 already has several at L9; Chapter 10 says some evolved. Make those evolutions named and useful.

### Basic Running / Basic Sprint
**Change:** Measurable speed and SP cost. e.g. +3–5% move or −5% SP cost per level (pick one primary). L9 evolve → **Running** / **Sprint**: burst or marathon specialty. Keep both if sprint is a separate resource spike.

### Basic Climbing
**Change:** Surfaces he can attempt; fall risk down. L9: rough dungeon walls without tools. Evolve → **Climbing** / free-climb under load (armor weight matters for ranged kit).

### Basic Sneaking
**Change:** Noise radius and detection checks. L9: approach within bolt range of unaware goblins. Evolve → **Stealth**. Critical for ambush ranged opener.

### Basic Hand to hand combat
**Change:** Keep as emergency. Damage/clinch escape only. Do not push as main. Evolve → **Hand to Hand** low priority.

### Basic Throwing
**Change:** Feeds Marksmanship / thrown weapons. Evolve toward a higher **Throwing** form that supports grenades, rune stones, bearings. Align with ranged focus; better investment than sword.

### Basic One-handed Swordsmanship
**Change:** Backup only. Cap investment; evolve only if forced. Prefer not to mirror Source melee grind. Optional: stall at mid level.

### Basic Leather Armor proficiency
**Change:** Reduce AGI/DEX penalty in leather; quieter movement. Evolve → leather/medium runic coat proficiency that fits shooter’s kit, not plate fantasy early.

### Reading proficiency
**Change:** Literacy speed/comprehension floor. Early and high. Evolve → scholarly reading; stacks with Hastened Reading (one = language/format, one = speed).

### Basic Mana Reinforcement
**Source:** skill book after abyss assassination (~Ch 54–56). Breathing drill. Adds a % of mana to base stats: **1% per level, 9% at Basic max**; Source T2 ~25%, T3 ~50%.
**Rewrite unlock:** self-taught in Ch 9.5 Carwen town absorb drills (no gnome/shop book).
**Sheet pads:** **Intelligence +1 / Willpower +1 per level** (same as Basic Incantation).
**Early-story constraint (Ch 1–70):** fights and basic runecraft still burn the pool. Reinforcement does not replace Regulation / Rune Mastery for staying in the fight; it only answers “how hard is my body while I still have mana.”
