# Status Breakdown

Three buckets for every attribute on Roland’s sheet. Use this when rewriting early chapters.

```
Displayed = Body + Class levels + Skills/Traits + Other
```

**Other** is residual only: slow Cha/Luck ticks and any story exception. Prefer putting growth into Body, Class or Skills/Traits when you can name the source.

## Bucket definitions

### 1. Body

Age + daily training from `Progression.md`. Physicals from the trained body table. Mentals from the **adult-mind** Int/Will table (4 hours reading daily). Cha/Luck stay as personal seeds until named growth.
