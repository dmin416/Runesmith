## System / class lore learned

- **Ascension ritual at age 10**: free **ascension stone/orb** → first class, no choice; taken to a personal ritual space.
- Later stones bought; further uses need **trials**; Tier 2 needs at least one maxed Tier 1 class among other reqs.
- Common Tier 1: Warrior, Archer, Mage, Thief, Blacksmith, Acolyte (combat vs production; more exist).
- Mage leans on INT (attack/mana) and Will (concentration, mana regen).
- Family wants him to **max mana-related skills before ascension** for Mage.
- Pre-ascension XP is banked with a **penalty** (anti–child farming rule); First Kill XP tingles then is blocked until class.
- Evolved Identify needed to read others’ full status (expensive); Baron used cheap orb instead.
- Skill unlock rules: mostly **combat-useful** basics before class; toys may fail (ball) while rock vs dummy works; production/class skills generally locked until class (smithing).
- Climbing level thresholds tested: L1 at first success, L2 after ~10, L3 after ~50 (not a flat ×10 forever).
