## New plan: Runesmith route

Path sketched from books:

1. Keep grinding Mage (dead-end combat but bankable).
2. Tier 1 **Blacksmith** (Dex primary + Str/End).
3. Tier 1 **Mana Scribe** (requires Calligraphy + Mage) → one-use scrolls; weak leveling, side income.
4. Tier 2 **Runesmith** (preferred) or Enchantsmith; both need Scribe; Runesmith needs learned rune skill (study, no shortcut); runes ≈ symbol language (harder/better than enchant “English”).
5. Later Weaponsmith/Armorer → Master Smith → Grandmaster Smith as smith tree.

Money and independence > army barracks. INT + Dex + mana favor runes.
